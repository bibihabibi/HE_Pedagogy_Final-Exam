# HE_Pedagogy_Final-Exam
Learning Support Hub
Learning Landscape + Student Support Simulator
Course: Minds and Machines in Learning | Group: ADA-2601M
Overview
Learning Support Hub is an interactive educational prototype designed to help university instructors recognize learning-support needs and help students access course materials. The system emphasizes formative feedback, inclusion, and human judgment rather than automated student classification.
Key Features
- Separate Instructor and Student interfaces.
- Instructor dashboard with fictional student profiles and transparent support indicators.
- Course resources, learning activities, flashcards, quizzes, and reflections.
- Instructor–student messages and predefined support-message templates.
- Accessibility options and multilingual communication examples.
- Local browser storage for demo changes, with an option to reset the demo.
How to Run
1. Download Learning-Landscape-Student-Support-Hub-Role-Separated.html.
2. Open the HTML file in a modern web browser (e.g., Chrome or Edge).
3. Switch between Instructor and Student views to explore the prototype.
No installation, server, or external database is required.
Technologies
- HTML5 — application structure.
- CSS3 — layout, styling, and responsive interface.
- JavaScript — interactions, simulated data processing, navigation, and browser storage.
Important Limitations
This is an offline demonstration with fictional student data. Its support indicators use fixed, transparent rules, and suggested messages use predefined templates. No live AI model is integrated, and the prototype should not be used for real student evaluation or consequential decisions. Secure authentication, institutional data integration, and production-grade privacy controls are future work.
